# Koa’s Events — Proposed Business Rules for Approval

Status: **PROPOSED — recommendations only; not yet controlling policy**

These recommendations are intentionally separate from `business-rules-source-of-truth.md`. Source-derived facts remain unchanged until Christopher approves a new policy and the client documents are updated to match.

## 1. Venue capacity

### Current source conflict
- Venue Rental Agreement: maximum occupancy 50, strictly enforced.
- Client Welcome Summary: maximum guests 100.

### Recommendation
Use **50 guests as the public launch capacity** unless and until Koa’s formally documents that a 100-person configuration is permitted by the controlling occupancy, insurance, parking, restroom, fire/life-safety and operational constraints.

If a larger configuration is valid, define separate capacities rather than one universal number, for example:
- seated reception capacity,
- ceremony capacity,
- cocktail-style capacity,
- pavilion-only capacity,
- full-property capacity.

Reason: capacity is a safety and contractual fact, not a marketing number. The signed/rental agreement currently contains the stricter rule.

## 2. Wedding packages

### Recommendation
Keep the four existing names because they create a useful value ladder, but reposition them by use case:

- **Gardenia — Intimate Weekday**: short ceremony / micro-event entry point.
- **Orchid — One-Day Venue**: core venue rental.
- **Hibiscus — Weekend Experience**: extended access + coordination/hospitality.
- **Plumeria — Full-Service Celebration**: premium, highly inclusive experience.

Use **“starting at”** pricing on the public site:
- Gardenia — from $1,500
- Orchid — from $3,000
- Hibiscus — from $8,000
- Plumeria — from $20,000

Do not change these dollar amounts until the cost/margin model is reviewed.

### Required cleanup
Every package should show these separately:
1. Maximum permitted attendance.
2. Included table/chair inventory.
3. Access hours/days.
4. Included services.
5. Optional add-ons.
6. What requires a custom quote.

Never use included furniture quantities as a proxy for event capacity.

## 3. Public pricing structure

### Recommendation
Use transparent **starting prices**, not hidden “contact us for everything” pricing and not an unconditional all-in fixed total.

This gives qualified shoppers enough information to self-select while protecting Koa’s from guest-count, staffing, travel, rental and customization variables.

The final proposal should be the controlling event total.

## 4. Mobile Bar service model

### Recommendation
Standardize the language site-wide:

> Koa’s Mobile Bar is a dry-bar service. Koa’s does not sell alcohol. The client purchases the alcohol; Koa’s provides professional bar service, planning and the supplies included in the selected package.

Use the same definition in the site, proposals, FAQ and agreement.

## 5. Mobile Bar packages

### Recommendation
Keep the three current package tiers for now:

- **Oahu — from $1,200**: beer, champagne and wine.
- **Maui — from $1,500**: Oahu scope + two signature drinks.
- **Big Island — from $1,800**: Maui scope + mixed cocktails.

For events above the included operating assumptions, require a custom quote rather than relying only on a per-person surcharge.

## 6. Bartender labor and gratuity

### Current conflict
One current source describes a 25% bartender fee. Another offers 10% + tip jar or 25% with no tip jar.

### Recommendation
Remove percentage-based “bartender fee” language from the customer-facing package model.

Instead:
- include a defined amount of bartender labor in each package,
- state the staffing assumption clearly,
- charge a transparent additional bartender/hour amount when the event requires more labor,
- make gratuity optional,
- default to **no tip jar** for weddings and corporate events unless the client requests one.

Reason: mandatory percentage fees create quote ambiguity, especially when the percentage is described “per bartender.” Labor should be a cost; gratuity should be a gratuity.

## 7. Staffing thresholds

### Recommendation
Do not promise that one simple guest surcharge solves staffing.

Create operational thresholds based on:
- guest count,
- cocktail complexity,
- service duration,
- whether beer/wine is self-contained or cocktails are built,
- simultaneous service demand.

A practical quoting rule can then add staff when service quality requires it. The website should state that staffing is based on event scope rather than publish an oversimplified bartender-to-guest promise until the operating model is approved.

## 8. Travel

### Recommendation
Define one origin and one method.

Preferred rule:
- travel included within 20 miles of Koa’s Mountain View operating base,
- additional mileage charged at the published mileage rate,
- calculated as the actual service travel Koa’s must provide.

If bartenders are dispatched from a different base and that is the real cost driver, state that in the quote terms rather than calling it “mobile bar trailer mileage.”

## 9. Guest-count overage for Mobile Bar

### Recommendation
Do not use “$8 per guest over 100” as the only scaling mechanism.

For more than 100 guests, use a custom quote that recalculates:
- staff,
- ice,
- mixers,
- cups/glassware,
- service stations,
- setup/cleanup,
- travel/logistics.

A per-person component can remain inside that calculation if it accurately reflects consumables.

## 10. Add-on pricing

### Recommendation
Publish fixed prices only for standardized items whose cost is stable.

Good fixed-price candidates:
- additional service hour,
- glassware per piece,
- standardized champagne toast if the scope is fixed.

Use “from” or quote-only pricing for:
- balloon/visual décor,
- custom vinyl,
- personalized accessories,
- custom menus,
- champagne walls/towers,
- anything with vendor-production or design variability.

## 11. Kamaʻāina offer

### Recommendation
Avoid a permanent blanket percentage discount on prime dates.

Use a targeted resident benefit instead, such as:
- weekday/off-peak rate,
- complimentary standardized add-on,
- reduced venue upgrade fee.

This protects premium-date pricing while still creating a meaningful local benefit.

## 12. Reservation retainer

### Current documented rule
10% non-refundable deposit, due within 14 days.

### Recommendation
For future bookings, consider moving to a **25% non-refundable reservation retainer** if cash-flow and cancellation exposure justify it.

Do not implement this until:
- the contract is updated,
- the welcome summary is updated,
- invoice/payment schedules are updated,
- existing signed bookings are grandfathered under their existing terms.

If Koa’s prefers maximum accessibility over upfront cash flow, retain 10%.

## 13. Cancellation and date changes

### Current documented rule
- Full refund if cancelled within 15 calendar days of signing.
- After that, payments are non-refundable.
- One date change if requested at least eight months before the original event.
- $500 one-day / $1,000 weekend change fee.

### Recommendation
Keep the current rule for existing contracts. For future contracts, consider a tiered cancellation schedule only if Koa’s wants to reduce sales friction. Any change should be designed together with the payment schedule and then updated in every client document simultaneously.

## 14. Damage deposit, insurance and event rules

### Recommendation
Keep the currently documented framework:
- damage deposit $500 one-day / $1,000 weekend,
- event insurance proof 60 days before,
- vendor insurance proof 30 days before,
- pre-approved bartenders,
- no self-service bar,
- no shots after 8 PM,
- music off by 10 PM,
- setup no earlier than noon unless approved.

The 75 dB rule appears in the event-day checklist and should either be added to the controlling agreement/FAQ or removed from the checklist so it does not exist in only one operational document.
