## Customer journeys

### Venue journey
Discovery (Google, social, referral) → Home or /venue/ → understand setting + capacity + inclusions → choose event type → see packages / gallery / FAQs → check availability → provide date, guest count and priorities → tour/consultation.

Primary proof: property photography, what is included, rain/weather plan, access/timing, guest experience, reviews.

### Mobile Bar journey
Search/social/referral → /mobile-bar/ → understand dry-bar model → select service style → review package inclusions + travel/staffing/add-ons → FAQ → check availability → provide location, date, guest count and desired bar style → tailored quote.

Primary proof: professional setup, service flow, bartender experience, package clarity, venue coordination, photos of the bar in real events.

### Wedding journey
Wedding landing → choose Venue, Mobile Bar, or Both → understand ceremony/reception experience → packages → real wedding/gallery → wedding FAQs → check date → consultation/tour.

Critical question early: “Are you looking for our venue, bar service at another venue, or both?” This prevents wedding leads from entering the wrong funnel.

### Private-event journey
/private-events/ → select celebration type (birthday, shower, graduation, retirement, reunion, retreat, other) → choose venue / mobile bar / both → examples + flexible packages → inquiry.

Avoid a separate SEO-thin page for every party type unless search demand and content quality justify it.

### Corporate journey
/corporate-events/ → choose meeting/retreat/client event/team celebration → capabilities (AV, sound, layout, bar, vendor coordination, timing) → sample formats → request proposal.

Corporate copy should be less wedding-coded and more operational: objective, guest count, run of show, production needs, food/beverage, budget and billing contact.

## Unified inquiry flow

1. What are you booking? Venue / Mobile Bar / Both
2. Event type
3. Preferred date + alternate date
4. Guest count
5. Location (shown when Mobile Bar is selected)
6. Desired service/package level
7. Budget range
8. Contact details + preferred contact method
9. Notes / priorities
10. Source attribution

Use conditional logic so a 25-person venue wedding and a 150-person off-site bar inquiry do not see the same irrelevant questions.

## Conversion rules

- One dominant CTA site-wide: Check Availability.
- Secondary CTA varies by context: Explore Venue, See Bar Packages, View Gallery.
- Do not repeat a full multi-field form at the bottom of every page.
- Use persistent CTA on mobile.
- Track availability_started, service_selected, inquiry_submitted, phone_clicked, email_clicked, package_viewed and gallery_engaged.
