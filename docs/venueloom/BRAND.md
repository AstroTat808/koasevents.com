# VenueLoom Brand Identity

## Brand idea

**VenueLoom** is the operating system for independent event venues.

The name combines the category ("Venue") with the idea of a loom: one system weaving sales, clients, contracts, payments, vendors, staff, planning, and event operations into a coherent business.

## Primary positioning

**Tagline:** The operating system for independent event venues.

**Supporting line:** From inquiry to event day, weave every part of your venue into one system.

**Short descriptor:** Venue Operations Platform

## Brand personality

VenueLoom should feel:
- operationally competent, not corporate-bureaucratic;
- premium, not luxury-for-luxury's-sake;
- calm under pressure;
- modern but not trendy;
- hospitality-aware;
- trustworthy around contracts, payments, staff, and client data.

Avoid visual language that feels like generic wedding software, floral stationery, or a developer-only infrastructure product.

## Logo system

### Primary concept: The Weave V

The primary mark is a geometric V built from overlapping paths. It communicates:
- V for Venue;
- woven threads;
- multiple operational workflows converging into one platform;
- forward/downstream movement from inquiry to event day.

Assets:

### Secondary logo concepts for later exploration

1. **Loom Gate** — two vertical rails with an interlaced horizontal thread, subtly resembling a venue doorway.
2. **Event Thread** — a continuous single-line V/L monogram whose path forms connected workflow nodes.
3. **Woven Calendar** — a restrained grid motif where two cells interlock into a V; suitable for the SaaS dashboard/app icon.

The Weave V is the default concept for implementation because it remains legible at favicon size and does not depend on wedding imagery.

## Color system

| Token | Hex | Use |
|---|---|---|
| Loom Ink | `#18242B` | Primary navigation, headings, dark surfaces |
| Thread Blue | `#4357F5` | Primary action, links, active states |
| Loom Teal | `#18A999` | Success, connected workflows, secondary accent |
| Spool Gold | `#D8A84E` | Premium/attention accent; sparingly |
| Canvas | `#F7F5EF` | Warm application/marketing background |
| White | `#FFFFFF` | Cards and high-contrast content |
| Slate | `#59636A` | Secondary text |

Do not use Spool Gold as a primary CTA. Blue is the primary interactive color; teal is functional; gold is editorial/premium emphasis.

## Typography

### Product/UI
**Manrope** — navigation, controls, tables, labels, metrics, forms.

Fallback: Inter, system sans-serif.

### Marketing/display
**Fraunces** — selective marketing headlines and editorial moments.

Fallback: Georgia / Times New Roman.

The application itself should remain mostly Manrope for density and readability.

## Iconography

Use simple 1.75–2px outlined icons with rounded joins. Avoid wedding-specific symbols as global navigation icons.

Module concepts:
- Sales: pipeline
- Events: calendar/check
- Clients: people
- Vendors: storefront/briefcase
- Team: badge/users
- Finance: receipt/chart
- Automations: connected nodes
- Insights: graph
- Admin: sliders/shield

## App icon and favicon

The app icon uses the Weave V on Thread Blue. The favicon uses the same shape on Loom Ink for stronger small-size contrast.

## SaaS website direction

### Homepage narrative

1. **Hero**
   - Headline: "Run your venue from first inquiry to final walkthrough."
   - Subhead: "VenueLoom brings sales, contracts, payments, planning, vendors, staff, and event operations into one connected workspace."
   - CTAs: "Book a demo" / "See how it works"

2. **Operational pain**
   - Replace disconnected spreadsheets, generic CRMs, inbox searches, and calendar juggling.

3. **Continuous event lifecycle**
   - Inquiry → Proposal → Contract → Payment → Planning → Vendors → Staff → Event Day → Review.

4. **Module story**
   - Sales, Events, Vendors, Team, Finance.

5. **Proof**
   - Koa’s Events as a founding design partner once productization is ready to be presented publicly.

6. **Automation**
   - Explain rules, reminders, sync, and operational alerts in plain language.

7. **Security/trust**
   - Tenant isolation, permissions, audit history, encrypted integrations, backups, status monitoring.

8. **Pricing**
   - Three simple tiers plus multi-venue.

9. **Final CTA**
   - "Bring every thread of your venue together."

### Visual system

- Warm Canvas backgrounds with white data cards.
- Large Loom Ink headings.
- Thread Blue CTAs.
- Product UI screenshots should dominate over generic venue stock photography.
- Use real venue photography only to establish hospitality context.
- Use thin "thread" connector lines to visually link workflow cards.
- Prefer editorial whitespace and dense, credible product screenshots over decorative gradients.

## Voice

Use clear operational language:
- "See what needs attention."
- "Know who owns each task."
- "Keep every vendor requirement current."
- "Turn a signed proposal into an event plan automatically."

Avoid:
- exaggerated AI claims;
- "revolutionary";
- "effortless everything";
- wedding-only language;
- generic productivity jargon.

## Accessibility

- Maintain WCAG AA text contrast.
- Never communicate status only through color.
- All interactive states require visible focus treatment.
- Brand marks must have monochrome alternatives.
