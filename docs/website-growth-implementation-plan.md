## Phase 1 — Flagship wedding conversion path

| Recommendation | Decision | Action |
|---|---|---|
| Clarify positioning above the fold | IMPLEMENT, MODIFIED | Use “A private rainforest wedding venue on Hawaiʻi Island” as category language and retain “Big Island celebrations, beautifully hosted.” as the brand headline. |

| Dedicated flagship landing page | IMPLEMENT NOW | Build /signature-wedding/ around estate, ceremony, reception, bar, celebration and planning team. |

| Show lower-cost packages equally | REJECT | Move Gardenia, Orchid and Hibiscus under “Other Ways to Celebrate at Koa’s.” |
| Change venue capacity to 50 | REJECT | Approved venue maximum remains 100 persons. Package-included furniture remains separate. |

## Phase 2 — Wedding inquiry and consultation funnel

| Recommendation | Decision | Action |
|---|---|---|
| Simplify wedding inquiry | IMPLEMENT NOW | Dedicated short /wedding-inquiry/ form: contact, primary/alternate date, guest count, budget, local/destination, package interest and vision. |
| Detailed equipment questionnaire before consultation | REJECT | Rentals, décor, bar accessories and production questions move downstream after qualification. |
| Dedicated wedding thank-you page | IMPLEMENT NOW | Build /wedding-inquiry-thank-you/ with three next steps and discovery-call request. |
| Immediate live calendar booking | IMPLEMENT LATER | Interim call-preference form now; replace with live scheduling once a calendar provider is selected. |
